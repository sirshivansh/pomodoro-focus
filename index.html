PomoFocusTrack

A production-grade, cloud-synchronized Pomodoro productivity suite. Built with an agency-grade design philosophy for users who demand both beauty and reliability.

Quick Start View Stack

Standout Features

What makes PomoFocusTrack different from a simple timer.

Secure Cloud Synchronization

Powered by Passport.js and secure cookie-based sessions. Every completed Pomodoro cycle is instantly synced to a serverless PostgreSQL database. Log in on any device and see your updated focus history and streaks — no more localStorage lock-in.

Dynamic Productivity Analytics

A GitHub-style weekly heatmap visualizes focus intensity with dynamic color saturation. An intelligent streak algorithm calculates "Current" and "Best" daily focus streaks to incentivize long-term habits.

Gamified Achievement System

Tiered achievement badges — Novice, Scholar, Deep Work Master — unlock as users accumulate focus minutes. Badges trigger an immersive glowing pop-up animation to reward milestone moments.

Agency-Grade UI/UX Design

Custom "Neo-Earthen" dark theme with complex radial gradients, futuristic typography (Space Grotesk & Rajdhani), glassmorphism effects, and fluid layout transitions orchestrated by Framer Motion.

Premium Mini-Timer Window

Pop out a compact, content-only timer window that stays on top. Perfect for monitoring your focus while working in other apps. Features its own "Click to Enable" audio activation and hover-based quick controls.

Real-Time Cross-Window Sync

Using the BroadcastChannel API, the main app and mini-timer stay perfectly in sync without backend latency. Pause, start, or reset in one window, and the other reflects it instantly.

High-Precision Quartz Engine

Upgraded countdown engine using the system clock (Date.now()) for absolute timing. Replaces traditional intervals to eliminate drift, ensuring your focus time is accurate to the millisecond.

Immersive Session Feedback

Brand-new glassmorphic completion overlays for both Focus and Break sessions. Clearly see your session status and your next scheduled task at a glance.

Unified Analytics Architecture

Complete overhaul of the analytics engine. Now tracks Focus, Short Break, and Long Break sessions together for a 100% accurate percentage breakdown of your day.

Secure Cloud Persistence

Hardened synchronization engine with secure credential handling. Your focus history and analytics are safely stored and accurately synced across all your devices.

Comprehensive History Tracking

Never lose a moment of work again. Every focus session and break interval is captured in a detailed, beautifully formatted timeline for effortless productivity review.

Customizable Timer

Adjust Work, Short Break, Long Break, and cycle count.

Auto-Progression

Seamless Focus → Break → Focus transitions.

Premium Hardware Audio

High-fidelity startup chimes and AI voice announcements for focus transitions.

Keyboard Shortcuts

Power-user hotkeys for pause, skip, and reset.

Motivational Quote Engine

Rotating, context-aware productivity quotes during active focus sessions.

Premium Loading Experience

High-fidelity dark-mode skeletons and glowing animated loaders for a zero-latency feel.

1

User authenticates via Passport.js Local Strategy. Password is hashed with scrypt and verified against the database.

2

Session cookie is stored in PostgreSQL via connect-pg-simple, enabling server-side session validation on every request.

3

Timer completes a focus session → React Query mutation sends validated payload (Zod) → Express route inserts record via Drizzle ORM.

4

Analytics and streak data are computed server-side via SQL aggregation queries and returned to the client for rendering in the heatmap and chart components.

Getting Started

Set up your local development environment in minutes.

Prerequisites

  • Node.js 18+ and npm / pnpm
  • A Neon PostgreSQL database (free tier available)
  • Git for version control
1

Clone & Install

terminal 
# Clone the repository
git clone https://github.com/your-username/pomofocustrack.git
cd pomofocustrack

# Install dependencies
npm install
2

Configure Environment

.env 
# Database
DATABASE_URL=postgresql://user:pass@ep-xxx.region.neon.tech/dbname?sslmode=require

# Session Secret (generate a strong random string)
SESSION_SECRET=your-super-secret-session-key

# App
NODE_ENV=development
PORT=5000
3

Run Database Migrations

terminal 
# Push schema to database
npx drizzle-kit push

# Or generate & run migrations
npx drizzle-kit generate
npx drizzle-kit migrate
4

Start Development Server

terminal 
# Start both Vite dev server + Express backend
npm run dev

# → Client: http://localhost:5173
# → API:   http://localhost:5000

You're all set!

Open http://localhost:5173 in your browser. Create an account and start your first focus session.

API Reference

Core REST endpoints used by the frontend.

Authentication

Creates a new user account with encrypted password.

Request Body 
{
  "email": "user@example.com",
  "password": "securePassword123"
}

Authenticates user and establishes a session cookie.

Request Body 
{
  "email": "user@example.com",
  "password": "securePassword123"
}

Destroys the active session and clears the cookie.

Returns 204 No Content on success.

Focus Sessions

Returns all focus sessions for the authenticated user, including computed analytics (streaks, heatmap data).

Response (200) 
{
  "sessions": [
    {
      "id": 1,
      "type": "focus",
      "duration": 25,
      "completedAt": "2025-01-15T10:30:00Z"
    }
  ],
  "analytics": {
    "currentStreak": 5,
    "bestStreak": 12,
    "totalSessions": 87,
    "totalMinutes": 2175,
    "heatmap": [...]
  }
}

Records a completed focus or break session. Validated with Zod schema.

Request Body 
{
  "type": "focus",       // "focus" | "shortBreak" | "longBreak"
  "duration": 25,          // in minutes
  "completedAt": "2025-01-15T10:30:00Z"
}
